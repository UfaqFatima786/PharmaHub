# 💊 Pharma Hub

Pharma Hub is a modern, responsive, and user-friendly pharmacy website designed to provide customers with a seamless online medicine shopping experience. The website offers an attractive interface where users can explore medicines, healthcare products, and pharmacy services with ease.

🌐 **Live Demo:** https://pharma-hub.netlify.app/

---

## 📌 Project Overview

Pharma Hub is a front-end web application built to simulate an online pharmacy platform. It focuses on clean design, responsive layouts, and an intuitive user experience for browsing healthcare products.

---

## ✨ Key Features

- 💊 Modern Pharmacy Landing Page
- 📱 Fully Responsive Design
- 🛒 Product Cards with Images
- 🔍 Easy Product Browsing
- 🩺 Healthcare & Medicine Categories
- 🎯 User-Friendly Navigation
- 🎨 Attractive UI Design

1. Clone the repository

```bash

```

2. Open the project folder

```bash
cd pharma-hub
```

3. Open **index.html** in your browser.
